# Educação em Primeiro Lugar — Grupo 3 

Portfólio do Grupo 3 na disciplina **Análise de Dados para Pesquisas em Políticas Públicas (CGAPN)**, FGV EAESP, 2º semestre de 2026, com a professora Érica Siqueira.

## Sobre o repositório

Este repositório reúne os dois projetos desenvolvidos pelo grupo em Excel, ambos sobre **políticas públicas de educação**, iniciados em aula e finalizados em casa:

- **Projeto 1 — Simulador de Repasse do PNAE:** calcula o repasse anual de alimentação escolar de uma escola a partir das matrículas por modalidade, classifica o porte da escola e simula cenários de variação das matrículas. Inclui planilha Excel e um simulador interativo em HTML.
- **Projeto 2 — Painel do Censo Escolar:** trata e analisa os microdados do Censo Escolar 2024 (estado de São Paulo) e os apresenta em um dashboard com tabelas dinâmicas, gráficos e segmentação de dados.
