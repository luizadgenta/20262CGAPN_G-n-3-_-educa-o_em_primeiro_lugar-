# Educação em Primeiro Lugar — Grupo 3 

Portfólio do Grupo 3 na disciplina **Análise de Dados para Pesquisas em Políticas Públicas (CGAPN)**, FGV EAESP, 2º semestre de 2026, com a professora Érica Siqueira.


## Objetivo do repositório

Reunir, em quatro entregas e suas versões atualizadas, ferramentas de análise de dados aplicadas a duas políticas públicas de educação no Brasil:

- **Alimentação escolar (PNAE):** quanto a União repassa a uma escola, de que depende esse valor e se ele é suficiente para cobrir o custo dos alimentos.
- **Infraestrutura e porte das escolas (Censo Escolar 2024, INEP):** como as escolas se distribuem por tamanho, dependência administrativa, localização e acesso a água, energia, esgoto e coleta de lixo.

Cada projeto foi construído primeiro em Excel (Projetos 1 e 2, com automações em VBA e Power Query) e depois em Python (Projetos 3 e 4, com pandas e Streamlit).

## Pastas do repositório

| Pasta | O que é | Ferramenta |
| --- | --- | --- |
| [`projeto-1-simulador-pnae`](./projeto-1-simulador-pnae) | Simulador de repasse do PNAE: matrículas por modalidade, porte, repasse anual, elegibilidade e cenários de variação. Inclui planilha e simulador HTML. | Excel, HTML |
| [`projeto-1-atualizado-com-automacao-vba`](./projeto-1-atualizado-com-automacao-vba) | O mesmo simulador, com macro que registra cada simulação (data, fator, racional e usuário) em um banco de dados. | Excel, VBA |
| [`projeto-2-painel-censo`](./projeto-2-painel-censo) | Painel do Censo Escolar 2024 (estado de São Paulo) com tabelas dinâmicas, gráficos e segmentações. | Excel |
| [`projeto-2-atualizado`](./projeto-2-atualizado) | Painel com a base nacional do Censo Escolar, filtrada por município dentro do Power Query. | Excel, Power Query |
| [`projeto-3-simulador-pnae-python`](./projeto-3-simulador-pnae-python) | Simulador do PNAE em Python, aplicado a uma escola real, com cálculo da cobertura do custo dos alimentos pelo repasse federal. | Python |
| [`projeto-4-painel-censo-python`](./projeto-4-painel-censo-python) | Painel interativo do Censo Escolar (30 municípios de SP em 4 regiões), com filtros, gráficos e mapa. | Python, pandas, Streamlit |

Cada pasta tem um README próprio com objetivo, instruções de uso, prints e os três disclaimers (uso de Inteligência Artificial, fonte de dados e participação do grupo).

## Por onde começar

- Quer ver o cálculo do repasse do PNAE? Comece pelo Projeto 1 (Excel/HTML) ou pelo Projeto 3 (Python).
- Quer explorar dados do Censo Escolar? Comece pelo Projeto 4 (painel no navegador) ou pelo Projeto 2 (Excel).
